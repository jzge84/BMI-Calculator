# BMI Calculator

This project is a simple web-based Body Mass Index (BMI) calculator that allows users to input their weight and height to calculate their BMI. The application provides a user-friendly interface and displays the calculated BMI along with a category based on the result.

## Project Structure

```
bmi-calculator
├── src
│   ├── index.html        # Main HTML document for the BMI calculator
│   ├── styles
│   │   └── main.css      # CSS styles for the user interface
│   ├── scripts
│   │   └── calculator.js  # JavaScript logic for calculating BMI
│   └── assets
│       └── .gitkeep      # Keeps the assets directory tracked by Git
├── README.md             # Documentation for the project
└── .gitignore            # Specifies files and directories to ignore by Git
```

## How to Use

1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd bmi-calculator
   ```

3. Open the `src/index.html` file in your web browser to access the BMI calculator.

4. Enter your weight (in kilograms) and height (in meters) in the provided input fields.

5. Click the "Calculate BMI" button to compute your BMI.

6. The result will be displayed below the button, along with a category indicating whether you are underweight, normal weight, overweight, or obese.
